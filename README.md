# The Moss Gate

Single-file dungeon crawler level for the Taskmarket “Add a tiny dungeon crawler level” bounty. Open `level-1.html` in a modern desktop browser; it needs no install or network connection.

The level uses a fixed 20×12 ASCII grid, WASD or arrow-key movement, wall collisions, two pursuing monsters, five HP, stairs, win/game-over states, and `R` to restart.
